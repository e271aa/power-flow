# PowerFlow brand

The mark is the three nodes of the flow: the adapter (green, left), the system
(blue, right, the largest) and the battery (amber, below), joined by the links
power travels along. The symbol keeps the geometry of the app icon,
[`AppIcon.svg`](AppIcon.svg), without its background.

## Files

| File | Use |
|---|---|
| `AppIcon.svg` | The app icon. `app/build.sh` renders it into `AppIcon.icns` |
| `icon-1024.png` | The app icon at 1024 × 1024 px |
| `symbol.svg` | The symbol in colour, on a transparent background |
| `symbol-mono-black.svg` / `symbol-mono-white.svg` | The symbol in one colour |
| `logo-light.svg` | Symbol and wordmark, for light backgrounds |
| `logo-dark.svg` | Symbol and wordmark, for dark backgrounds |
| `logo-mono-black.svg` / `logo-mono-white.svg` | Symbol and wordmark in one colour |

## Colours

| Part | Hex |
|---|---|
| Adapter links (to the system and to the battery) | `#4CC27A` |
| Adapter node | `#52C881` |
| System node | `#5C9BEB` |
| Battery link | `#F2B544` |
| Battery node | `#F7BC4B` |
| Icon background | `#40434A` (top) to `#1B1D21` (bottom) |
| Wordmark on light | `#1D1D1F` |
| Wordmark on dark | `#F5F5F7` |
| One colour | `#000000` or `#FFFFFF` |

The colours are the same in light and dark: only the wordmark changes.

## Wordmark

"PowerFlow" is drawn, not typeset: one line weight with round ends and joins,
like the links of the symbol. The cap height equals the symbol's height, and
the gap between them is a third of it. Do not retype it in a font.

## Space and sizes

- Keep clear space around the logo at least the diameter of the battery node.
- Minimum sizes: logo 16 px tall, symbol 12 px tall.
- Do not recolour single nodes, rotate the symbol, or put the colour logo on a
  busy or mid-tone background; use a one-colour version there.
